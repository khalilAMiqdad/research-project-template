# fieldwork

| File | Content |

| `FIELDWORK_MANUAL.md` | Procedures for interviewers and supervisors |
| `training/` | Training agenda, materials, test results (aggregate) |
| `YYYY-MM-DD_fieldwork_progress.md` | Daily/weekly progress: completes, refusals, QC flags — **aggregate only** |

**Never** store here: interviewer–respondent lists, contact details, GPS points, audio,
photos, or completed paper forms. Those belong to `$DATA_ROOT/restricted/`.
Refer to interviewers by code (`INT-07`), not by name, in shared QC summaries.
