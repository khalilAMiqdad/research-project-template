# tasks

Tasks are managed as **GitHub Issues** on the Project board, not as files — this keeps
owner, status, discussion and the linked Pull Request in one traceable place.
See [PROJECT_BOARD.md](../../06_documentation/governance/PROJECT_BOARD.md).

This folder may hold exported work-plans (e.g. Gantt for funders) named `YYYY-MM-DD_workplan.<ext>`.
